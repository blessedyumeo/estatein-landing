# Estatein — вёрстка по макету

🔗 **Live demo:** _ссылка появится после первого запуска deploy.bat_
🎨 **Макет:** [Estatein — Figma Community](https://www.figma.com/design/SpHNEeDtniogq1vsg6T8sx/Estatein) (by Produce UI)

Многостраничный сайт агентства недвижимости, свёрстанный по макету из категории
«сложные» на [verstaem.online](https://verstaem.online/layouts/estatein):
6 страниц, три брейкпоинт-фрейма (1920 / 1440 / 390), слайдеры, галерея, формы.

`HTML5` · `CSS3 (Grid + Flexbox + custom properties)` · `Vanilla JS` ·
без фреймворков, без сборщика, без зависимостей.

## Как открыть

Просто открой `index.html` в браузере — всё работает с `file://`,
внешних зависимостей нет (шрифт Urbanist подгружается с Google Fonts,
без интернета подставляется системный fallback).

Если хочется локальный сервер:

```bash
python -m http.server 8080
# затем http://localhost:8080
```

## Публикация на GitHub Pages

В корне лежит `deploy.bat` — двойной клик, и он сам:
инициализирует git, делает коммит, создаёт публичный репозиторий,
пушит код, включает GitHub Pages и вписывает ссылку на демо в этот README.

Нужен [Git for Windows](https://git-scm.com/download/win); желательно ещё
[GitHub CLI](https://cli.github.com/) (`winget install --id GitHub.cli`) —
с ним всё делается полностью автоматически. Без gh скрипт напишет,
какие две команды выполнить руками.

## Адаптив

Брейкпоинты подобраны под три фрейма макета (Desktop 1920 / Laptop 1440 / Mobile 390):

| Ширина | Что меняется |
|---|---|
| ≥ 1900 | поля 160 px, H1 48 px, слайдеры по 3 карточки |
| ≥ 1600 | поля 120 px |
| ≥ 1200 | поля 80 px |
| ≥ 1024 | десктопная навигация, двухколоночный герой, 4 колонки в сетках |
| ≥ 768 | поля 40 px, 2 колонки в сетках и слайдерах |
| < 768 | бургер-меню, всё в одну колонку, картинка героя над текстом (как в мобильном фрейме макета) |

Горизонтального скролла нет ни на одной странице ни на одной из проверенных ширин
(1920 / 1440 / 1024 / 768 / 390).

## JS

* **Слайдеры** — «Featured Properties», отзывы, FAQ, клиенты. Кнопки-стрелки,
  счётчик вида `01 of 60`, свайп на тач-устройствах, пересчёт при ресайзе.
* **Бургер-меню** — полноэкранное, блокирует скролл, закрывается по Esc и по клику на пункт.
* **Галерея объекта** — превьюшки + пара крупных фото + точки-пагинация + стрелки.
* **Табы офисов** на странице контактов (All / Regional / International).
* **Формы** — базовая валидация обязательных полей и e-mail, статус отправки,
  подсветка ошибочных полей (реальной отправки нет — это вёрстка).
* **Топбар** — закрывается крестиком, состояние помнится в рамках сессии.
* **Reveal** — мягкое появление секций на IntersectionObserver.

Всё уважает `prefers-reduced-motion`.

## Доступность и семантика

* Осмысленные теги: `header / nav / main / section / article / footer`, списки для списков,
  `dl` для характеристик объекта.
* `aria-current="page"` у активного пункта меню, `aria-expanded` у бургера,
  `aria-label` у иконочных кнопок, `role="status"` у статуса формы.
* Видимый фокус (`:focus-visible`), скрытые, но доступные подписи (`.visually-hidden`).
* Контрастная тёмная тема, как в макете.

## Про картинки

Фотографий в макете нет в свободном доступе (Figma не отдаёт исходники без экспорта),
поэтому вся графика — **сгенерированные SVG-заглушки** в фирменной палитре:
небоскрёбы, виллы, коттеджи, интерьеры, офисные сцены, аватары, фоновые паттерны.
Они лежат в `img/` и собираются скриптом `tools/genimg.py`.
Чтобы поставить реальные фото — просто замените файлы в `img/`,
размеры и пропорции в CSS уже заданы (`aspect-ratio` + `object-fit: cover`).

## Отличия от макета (осознанные)

* Год в подвале подставляется скриптом (в макете жёстко `@2023`).
* Тексты и данные — из макета, без изменений.
* Слайдеры листают реальные карточки; счётчики (`of 60`, `of 10`) взяты из макета
  как декоративные, реальное число слайдов меньше.
